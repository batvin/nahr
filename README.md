# نهر (Nahr)

تونل رمزنگاریشدهٔ چندترنسپورته با پنل وب RTL و محک داخلی. از صفر نوشته شده؛ هیچ کدی از پروژهٔ Kariz کپی نشده است (مجوز آن source-available است).

- ترنسپورتهای پشتیبانی شده: `tcp`, `tcpmux`, `ws`, `wss`, `udp`
- رمزنگاری: X25519 + HKDF-SHA256 + AES-256-GCM، احراز هویت با توکن
- پنل فارسی، SOCKS5، فوروارد پورت ثابت، محک ۱۰ حالته و دموی محلی

## نصب تکخطی روی سرور (Ubuntu/Debian)

کافی است روی سرور خود این را بزنید؛ اسکریپت Node، کد، سرویسها و توکن را نصب میکند و آدرس پنل را چاپ میکند:

```bash
curl -fsSL https://raw.githubusercontent.com/batvin/nahr/main/scripts/quick-install.sh | sudo bash
```

خروجی مثال:

```
نهر نصب شد ✓
پنل:      http://127.0.0.1:18080/panel
توکن:     <hex>
برای دیدن پنل:
  ssh -L 18080:127.0.0.1:18080 root@<SERVER_IP>
  http://localhost:18080/panel
```

## منوی ترمینالی `nahr-manager`

اسکریپت نصب تکخطی، فرمان `nahr-manager` را هم در `/usr/local/bin` نصب میکند:

```bash
sudo nahr-manager
```

منوی فارسی و RTL باکلیدهای ↑/↓، شماره و Enter:

- نصب و بهروزرسانی نهر، وضعیت و آدرسها
- نصب/حذف پنل وب، لینک ورود، توکن و تغییر پورت پنل
- اتصال ایجنت به پنل، حذف ایجنت
- لاگ زنده و حذف کامل نهر (بعد از تایپ «بله»)

## وبسایت و موشن گرافیک

صفحهٔ فرود در `/` و مستندات در `/docs` با جلوههای موشن، تونل سهبعدی CSS، نمودار جریان متحرک و کارتهای تیلتدار ساخته شدهاند — بدون کتابخانهٔ خارجی و بدون مرحلهٔ ساخت. منوی ترمینالی هم در صفحهٔ فرود نمایش داده میشود.

## نصب دستی / دموی محلی

نیاز: **Node.js 20+** و npm. نیازی به کامپایلر نیست.

```bash
git clone https://github.com/batvin/nahr.git
cd nahr
npm install
npm test
```

اجرای دموی محلی (دو ایجنت + پنل):

```bash
npm run demo
```

سپس `http://localhost:8080/panel` را باز کنید.
