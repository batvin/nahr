مستندات

همهٔ آنچه برای اجرا و آزمایش نهر لازم است

نصب و اجرا

نیاز: Node.js ۲۰ یا بالاتر. نصب وابستگیها:

cd nahr npm install npm run demo # یا: npm start
  • npm start تنها پنل، وبسایت و مستندات را روی پورت ۸۰۸۰ بالا میآورد.
  • npm run demo علاوه بر پنل، دو ایجنت محلی و پنج تانل آزمایشی میسازد.
  • npm run bench محک را از خط فرمان بین دو سرور ثبتشده اجرا میکند.

معماری

ورودی (entry) یک پروکسی SOCKS5 ارائه میدهد. هر درخواست کاربر به یک جریان در مالتیپلکسر تبدیل میشود. جریانها روی یک یا چند اتصال ترنسپورت با رمزنگاری AES-GCM ارسال میشوند و خروجی (exit) آنها را به مقصد واقعی وصل میکند.

دست دادن کلید با X25519 انجام میشود و توکن مشترک تنها زمانی میپذیرد که طرف مقابل HMAC درستی را ارائه دهد. کلیدها با HKDF مشتق میشوند؛ نشت توکن، ترافیک ضبطشدهٔ گذشته را باز نمیکند.

ترنسپورتها

ترنسپورتزیرلایهبهترین کاربرد
tcpTCPسادگی، اتصال جداگانه برای هر جریان
tcpmuxچند اتصال TCPپیشفرض؛ مسیر تمیز، بهترین throughput
wsWebSocket / HTTPپشت CDN یا پروکسی معکوس
wssWebSocket / TLSوقتی لازم است شبیه HTTPS دیده شود
udpUDP + ARQمسیر پراتلاف، بازی، صوت

ترنسپورت UDP از نوع KCP الهام گرفته شده ولی با آن سازگاری سیمی ندارد. بستهها با nonce تصادفی مهروموم میشوند، شمارهٔ توالی و ACK تجمعی دارند و بستهٔ گمشده دوباره فرستاده میشود.

پروفایلها

  • متعادل (balanced): ۳ اتصال، MTU ۱۲۰۰ — حالت عمومی
  • حداکثر سرعت (ultraspeed): ۶ اتصال، MTU ۱۴۰۰ — انتقال حجیم
  • بازی (gaming): ۲ اتصال، MTU ۱۰۰۰، بازارسازی سریعتر — تأخیر پایدار

محک چگونه کار میکند؟

  1. برای هر ترنسپورت و هر دو جهت (مستقیم و معکوس) یک شنوندهٔ موقت روی یک سرور و یک شمارنده روی سرور مقابل راهاندازی میشود.
  2. مرحلهٔ کاوش: چند ping کوتاه برای تشخیص عبور و تأخیر.
  3. مرحلهٔ سرعت: سه گزینهٔ برتر، دانلود و آپلود چندجریانه.
  4. امتیاز: weighted speed + latency + stability. وزنها بسته به پروفایل تغییر میکند.
  5. دکمهٔ «اعمال بهترین» ترنسپورت تانل را عوض میکند.
محک از ترافیک واقعی استفاده میکند و روی مسیر شما اجرا میشود؛ نتایج یک نمونهاند، چند بار اجرا کرده و میانه را در نظر بگیرید.

سرور واقعی

node bin/nahr.js agent --port 7700 --id s1 --host 0.0.0.0

سپس در پنل، تب «سرورها» → «افزودن سرور»، آدرس و پورت ایجنت را وارد کنید. توکن پیشفرض همان کلید مشترک پنل است (قابل مشاهده در تنظیمات). پورت ۷۷۰۰ ایجنت را در فایروال باز کنید.

اتصال دو سرور با یک کد

وقتی نهر روی سرور اول (جایی که پنل است) نصب شد، نیازی نیست روی سرور دوم هم پنل نصب کنید یا پورت ۱۸۰۸۰ را باز بگذارید. روی سرور پنل کد اتصال بسازید:

sudo nahr-manager # گزینهٔ 10: ساخت کد اتصال تکخطی # یا مستقیم از خط فرمان: nahr connect-code --agent http://IP_OF_PANEL_SERVER:7700 --name outside --ttl 24

خروجی، یک کد nh1_... و دستور کاملی است که باید روی سرور دوم اجرا شود:

bash <(curl -fsSL https://raw.githubusercontent.com/batvin/nahr/main/scripts/quick-install.sh) --agent nh1_...

اسکریپت ابتدا نهر را نصب/بهروزرسانی میکند، سپس کد را باز میکند، توکن و شناسهٔ سرور را از آن میخواند و سرور را از طریق ایجنت سرور پنل به پنل اضافه میکند. در پایان تنها سرویس nahr-agent روی سرور دوم فعال است.

  • پنل محلی میماند: ثبت سرور از طریق /connect/register روی ایجنت سرور پنل انجام میشود؛ پورت پنل باز نمیشود.
  • پیش از جایگزینی میپرسد: اگر شناسه یا IP سرور از قبل در پنل باشد، اسکریپت میپرسد «جایگزین شود؟». با --replace میشود بدون سؤال جایگزین کرد.
  • کد محرمانه است: حاوی توکن مشترک است و بهطور پیشفرض ۲۴ ساعت اعتبار دارد. آن را مثل توکن نگه دارید و در صورت نیاز کد تازهای بسازید.
همان کد را میشود در تب «تنظیمات» پنل هم ساخت: قسمت «اتصال سرور جدید با یک کد»، آدرس عمومی ایجنت سرور پنل را بدهید تا دستور تکخطی کپی شود. در تب «سرورها» هم دو کادر هست: یکی برای ساخت کد و دیگری برای چسباندن کد nh1_ و اضافه کردن سرور مستقیم از طریق وب — بدون رفتن به ترمینال. فهرست سرورها بهطور خودکار تازه میشود و سرور متصلشده بدون رفرش صفحه دیده میشود.
از نسخهٔ جدید، اعتبارسنجی کد توسط خود پنل انجام میشود؛ حتی اگر توکن سرویس ایجنت پنل قدیمی باشد، اتصال با کد معتبر کار میکند.

منوی ترمینالی nahr-manager

اسکریپت نصب تکخطی، فرمان nahr-manager را هم نصب میکند. با اجرای آن یک منوی فارسی و RTL میبینید:

curl -fsSL https://raw.githubusercontent.com/batvin/nahr/main/scripts/quick-install.sh | sudo bash sudo nahr-manager
  • نصب یا بهروزرسانی نهر: دریافت آخرین نسخه از گیت هاب و راهاندازی دوبارهٔ سرویسها.
  • وضعیت و آدرسها: نام میزبان، IPv4/IPv6، پورتها، تانلهای زنده و توکن (پوشاندهشده).
  • پنل وب: نصب/حذف پنل، لینک ورود، نمایش توکن و تغییر پورت پنل.
  • ایجنت: اتصال این سرور به پنل دیگری، ساخت کد اتصال تکخطی (nh1_) برای سرور خارج و متوقف کردن ایجنت.
  • سیستم: لاگ زندهٔ journalctl و حذف کامل نهر.
برای خروج از منو q یا Ctrl+C را بزنید. حذف کامل تنها بعد از تایپ عبارت «بله» انجام میشود.
