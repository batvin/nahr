همهٔ آنچه برای اجرا و آزمایش نهر لازم است

نصب و اجرا

نیاز: Node.js ۲۰ یا بالاتر. نصب وابستگیها:

cd nahr npm install npm run demo # یا: npm start
  • npm start تنها پنل، وبسایت و مستندات را روی پورت ۸۰۸۰ بالا میآورد.
  • npm run demo علاوه بر پنل، دو ایجنت محلی و پنج تانل آزمایشی میسازد.
  • npm run bench محک را از خط فرمان بین دو سرور ثبتشده اجرا میکند.

معماری

ورودی (entry) یک پروکسی SOCKS5 ارائه میدهد. هر درخواست کاربر به یک جریان در مالتیپلکسر تبدیل میشود. جریانها روی یک یا چند اتصال ترنسپورت با رمزنگاری AES-GCM ارسال میشوند و خروجی (exit) آنها را به مقصد واقعی وصل میکند.

دست دادن کلید با X25519 انجام میشود و توکن مشترک تنها زمانی میپذیرد که طرف مقابل HMAC درستی را ارائه دهد. کلیدها با HKDF مشتق میشوند؛ نشت توکن، ترافیک ضبطشدهٔ گذشته را باز نمیکند.

ترنسپورتها

ترنسپورتزیرلایهبهترین کاربرد
tcpTCPسادگی، اتصال جداگانه برای هر جریان
tcpmuxچند اتصال TCPپیشفرض؛ مسیر تمیز، بهترین throughput
wsWebSocket / HTTPپشت CDN یا پروکسی معکوس
wssWebSocket / TLSوقتی لازم است شبیه HTTPS دیده شود
udpUDP + ARQمسیر پراتلاف، بازی، صوت

ترنسپورت UDP از نوع KCP الهام گرفته شده ولی با آن سازگاری سیمی ندارد. بستهها با nonce تصادفی مهروموم میشوند، شمارهٔ توالی و ACK تجمعی دارند و بستهٔ گمشده دوباره فرستاده میشود.

پروفایلها

  • متعادل (balanced): ۳ اتصال، MTU ۱۲۰۰ — حالت عمومی
  • حداکثر سرعت (ultraspeed): ۶ اتصال، MTU ۱۴۰۰ — انتقال حجیم
  • بازی (gaming): ۲ اتصال، MTU ۱۰۰۰، بازارسازی سریعتر — تأخیر پایدار

محک چگونه کار میکند؟

  1. برای هر ترنسپورت و هر دو جهت (مستقیم و معکوس) یک شنوندهٔ موقت روی One سرور و یک شمارنده روی سرور دیگر راهاندازی میشود.
  2. مرحلهٔ کاوش: چند ping کوتاه برای تشخیص عبور و تأخیر.
  3. مرحلهٔ سرعت: سه گزینهٔ برتر، دانلود و آپلود چندجریانه.
  4. امتیاز: weighted speed + latency + stability. وزنها بسته به پروفایل تغییر میکند.
  5. دکمهٔ «اعمال بهترین» ترنسپورت تانل را عوض میکند.
محک از ترافیک واقعی استفاده میکند و روی مسیر شما اجرا میشود؛ نتایج یک نمونهاند، چند بار اجرا کرده و میانه را در نظر بگیرید.

سرور واقعی

node bin/nahr.js agent --port 7700 --id s1 --host 0.0.0.0

سپس در پنل، تب «سرورها» → «افزودن سرور»، آدرس و پورت ایجنت را وارد کنید. توکن پیشفرض همان کلید مشترک پنل است (قابل مشاهده در تنظیمات). پورت ۷۷۰۰ ایجنت را در فایروال باز کنید.
