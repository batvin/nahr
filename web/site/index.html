ONE CODE · TWO SERVERS

دو سرور، یک کد، یک دستور

روی سرور پنل کد اتصال بسازید و روی سرور خارج تنها همان یک خط را بزنید. نصب نهر، دریافت توکن و ثبت سرور خودکار میشود و پنل روی 127.0.0.1 میماند — نیازی به باز کردن پورت پنل نیست.

  1. روی سرور پنل: sudo nahr-manager → گزینهٔ ۱۰ «ساخت کد اتصال تکخطی» (یا nahr connect-code --agent http://IP:7700 --name outside).
  2. کد nh1_… را کپی و به سرور خارج بدهید.
  3. روی سرور خارج با root همان دستور تکخطی را اجرا کنید.

اگر سرور خارج از قبل به پنلی وصل باشد، اسکریپت پیش از جایگزین کردن میپرسد؛ برای حالت خودکار --replace را اضافه کنید. اعتبار پیشفرض کد ۲۴ ساعت است. همچنین میشود کد nh1_ را مستقیم در تب «سرورها»ی پنل چسباند و سرور را بدون ترمینال اضافه کرد؛ فهرست سرورها بهطور خودکار تازه میشود.

server-1 → server-2
# server-1 (panel): generate a one-time connect code
$ nahr connect-code --agent http://87.107.81.145:7700 --name outside
nh1_eyJ2IjoxLCJhIjoiaHR0cDovLzg3LjEwNy44MS4xNDU6NzcwMCIs…
 
# server-2 (root): install + join with that single code
$ bash <(curl -fsSL …/quick-install.sh) --agent nh1_eyJ2Ijo…
✓ نهر متصل شد · ایجنت 0.0.0.0:7700
